# Roam America v3.2 — 2026-09-15

This release adds itemized trip budgeting, complete local workspace backups and contextual 3D illustrations, and improves the initial 24 destination guides and 72 photo captions. All features run without a database connection.

## Delivered

- Trip budget with six categories, up to 200 expenses, group totals in USD, paid/remaining amounts and per-traveler estimates. Daily and itemized calculation modes do not double-count costs. Expenses persist, export in text/JSON and appear in the five-language print/PDF layout. Removing an expense supports undo.
- Full backup of the trip library (including archives), expenses, checklists, collections, visited places and saved states. File preview supports selecting individual trips, merging copies or replacing selected data groups. Validation and capacity checks run before any write. A rollback journal recovers interrupted writes and frees partial values before restoring old data when space is tight.
- More compact mobile planner utilities and heading, three view tabs and a fixed add-activity action that scrolls to and focuses the form.
- Locally rendered Golden Gate Bridge, New York Liberty and Monument Valley scenes; selected states drive the illustration, planned states get an outline, and remembered photo mode includes source credit. Reduced-motion, offscreen pause and unavailable-WebGL fallback remain supported.
- Destination-specific access guidance and editorial month tags for 24 places in eight states. Big Sur Station replaces one approximate area pin. The catalog contains 43 visitor-center references and 107 clearly identified area references.
- 72 descriptive five-language captions, including Canadian viewpoints in Niagara and historical eruption photographs in Hawaiʻi. The South Rim gallery now uses an appropriate Hermit Road image instead of the remote Nankoweap granary. Source and license metadata remain available.
- Saved, dated travel advisories in practical guides, daily schedules and generated HTML. The trip helper excludes advised destinations until editorial review clears them. Studio can edit advisories and per-language photo captions, with review flags reset after edits.
- Responsive homepage hero images: 339,444-byte original JPEG replaced with 480/960/1600-pixel WebP choices (21,082 / 71,516 / 169,206 bytes). High-density mobile selects 1600 pixels in the recorded run, approximately 50% fewer image bytes than the original.
- CI installs Chromium, Firefox and WebKit. The complete Chromium desktop/mobile suite and targeted Firefox/WebKit workspace journeys cover budgeting, backup restoration, language switching, responsive layout and scene fallbacks.

## Validation

- Production build and TypeScript check; content validation for 50 states, 150 places, 450 credited photos and five languages; Prettier and Git whitespace checks.
- 106 browser checks in the regular suite: complete Chromium desktop/mobile coverage plus critical journeys on Firefox desktop and WebKit touch emulation.
- Five production tests: no-JavaScript pages and SEO links, client navigation, offline photos/plans, five-language PDF output including expenses, and locally mocked account behavior. No real emails were sent.
- Local PGlite SQL compatibility tests pass. No Supabase project was linked, migrated or contacted.
- Visual inspection of desktop English and mobile Thai budget, planner, backup and three landmark scenes. No observed page errors or horizontal overflow in the captured journeys.

These are lab observations, not field Core Web Vitals or proof of physical-device performance. LCP remains above 2.5 seconds under this profile. The complete catalog chunk still triggers Vite's 500 kB warning (about 909 kB raw / 175 kB gzip); splitting detailed catalog data is a future performance task, not hidden by raising the warning limit.

Reproduce with `npm run build` then `node scripts/review-workspace.mjs`. Screenshots and JSON measurements are written to ignored `artifacts/v3.2/`.
