# Roam America 3.1 — local travel workspace

This release expands the travel experience without activating a database, Supabase project or account service. Local plans remain usable with no configuration.

## Delivered

1. A homepage entry strip for finding places, choosing a prepared itinerary and starting/resuming a plan.
2. A separate 150-place discovery view with combined filters, map selection, comparison and saving.
3. A three-step destination helper with explained matches and editable trip creation that preserves the previous trip.
4. A browser trip library with switching, duplication, archives, restoration, deletion confirmation and individual exports.
5. Compact daily activity editors, explicit times, editable transfer/rest buffers, overlap/distance warnings and mobile list/map navigation.
6. Eight daily itinerary templates, with city-specific afternoon suggestions and room for meals, rest and transfers.
7. Named place collections, visited markers and validated collection import/export with confirmation.
8. A per-trip preparation checklist, custom tasks and printable checklist/timing details.
9. Atlas zoom/reset/rotation, state and region focus, destination previews, schematic route markers and a local WebGL bridge illustration.
10. Practical planning tags, five-language experience copy and concise gallery labels, guide section navigation, eight reviewed access guides and three additional field guides.
11. Responsive WebP photos, original-image fallback, deferred page/component loading and offline download status/removal.
12. Desktop/mobile visual inspection, accessibility and regression checks, with a repeatable local performance/screenshot review.

## Verification

- Regular Playwright suite: 86 desktop/mobile cases.
- Production suite: 5 cases covering static language pages, client metadata, offline images, five-language PDF output and mocked account compatibility.
- SQL compatibility checks run locally in PGlite. Browser account requests are intercepted; neither suite provisions or contacts a real database or sends mail.
- Content validation checks 50 states, 150 profiles, 450 distinct credited photographs and five-language completeness.
- `npm run build`, `npm run format:check` and dependency audit are part of the release review.
- `node scripts/review-experience.mjs --production` starts an isolated preview on port 5177, writes screenshots and observations to ignored `artifacts/v3.1/`, then closes the preview. Build first. Without `--production`, it expects the dev server on port 5175.

## Image and loading observations

Across the 450 destination photographs, originals total 90,249,671 bytes. The generated 480-pixel WebP set totals 14,883,176 bytes (83.5% smaller), and the 960-pixel set totals 57,785,524 bytes (36.0% smaller). These are corresponding asset-set comparisons, not a promise about total page download size. The browser selects image size according to the displayed width and pixel density. Originals remain available for galleries and fallback.

The initial application module is about 321 kB / 106 kB gzip; the catalog is about 897 kB / 162 kB gzip. Guide, planner, dialogs, maps and the 4.7 kB bridge illustration have separate chunks. The catalog still triggers Vite's 500 kB raw-chunk advisory; this is retained rather than suppressed.

One local, unthrottled Chromium observation recorded FCP/LCP of 180/348 ms and CLS 0 on desktop (1440 × 1000, English), and 88/196 ms with CLS 0.0284 on mobile (390 × 844, Thai). These are lab observations on localhost, not production field Core Web Vitals or an INP measurement. The review found no runtime exceptions, broken loaded guide photos or horizontal overflow, including 320-pixel homepages in all five languages. The generated JSON records the environment and dimensions for each run.

## Editorial boundaries

Month and transport/walking tags are editable editorial starting points. Month tags initially follow state seasons. Walking classifications do not certify disability access. Eight popular-place transport/access paragraphs were checked against linked official operators and NPS guidance on 2026-09-14; this does not mark every profile as freshly reviewed.

The gallery uses localized place/photo identifiers while preserving original source captions and credit/license links. These identifiers do not claim to be full translations of each original caption. Native-speaker review remains visible in Studio. The existing 108 approximate-area coordinate records remain labeled; they have not been converted into unverified entrances or parking coordinates.

No hosting origin is configured in this repository. A push triggers GitHub verification; publishing the generated site remains the host's deployment step.
